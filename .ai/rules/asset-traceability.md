# Asset traceability (REQ-19)

## No table of its own
Traceability is built on read from the append-only audit tables that already exist; it stores nothing and does not copy the closure. Sources: `ticket_status_transitions` (REQ-14), `ticket_assignments` (REQ-15), `ticket_closures` (REQ-18, only to show the result of the "Cerrado" event) and `preventive_execution_status_transitions` (REQ-17). Do not add an events table: it would duplicate data and need a backfill.

## Events
`App\Services\BuildAssetTraceability::execute()` returns the events of an asset, newest first. Each carries `key`, `source` (`ticket` or `preventive`), `action`, `title`, `detail`, `note`, `user` (`{id, name}` or `null`), `occurred_at` (ISO 8601) and `url`. A `null` user is shown as "Sistema" (executions generated by a plan).
- Tickets: the first `ticket_assignments` row completes the "Asignado" event (responsible); every later row is a "Reasignado" event, because a reassignment writes no status transition.
- Preventive: a transition whose `from_status` equals its `to_status` is a postponement or a reassignment, told apart by the note prefix ("Aplazado", "Reasignado") written by `PreventiveMaintenanceExecution::postpone()` and `reassignTo()`. If those texts change, update `preventiveAction()`.
- Type dates as `Carbon\CarbonInterface`: the project returns `CarbonImmutable`.

## Query
`GET /asset-cards/{assetCard}/traceability` (`asset-cards.traceability`, invokable `AssetCardTraceabilityController`). Filters `?source=ticket|preventive` and `?user=<id>`, 25 events per page (`?page=`). Like every `asset-cards` route it sits in the `role:tenant_admin` group, so the service does not filter by user; if it is opened to other roles, apply the ticket (`TicketController::visibleTickets`) and preventive (`ResolvesPreventiveAccess`) visibility rules inside the service.

## Frontend
`Pages/AssetCards/Traceability/Index.tsx` with the types in `Types/AssetCards/Traceability.ts`. The asset card keeps the short list of `asset-card-history.md` and links here through the `traceabilityUrl` prop. Covered by `tests/Feature/AssetTraceabilityTest.php`.
